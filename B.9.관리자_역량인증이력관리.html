3 역량인증이력 목록
동작 규칙
  • 한 행 = 학생 1명이 프로그램 1건을 이수하고 역량점수를 인증(또는 취소)받은 이력 — 학생별 집계가 아닌 이수 건별 1행
  • 컬럼 순서 : 선택 체크박스 → 이름(최우선 식별) → 아이디 → 학교급 → 학교 → 학년 → 프로그램명 → 다면적 역량 → 점수 → 구분 → 처리일(최후미)
  • 인증 이력과 취소 이력을 동시에 표시 — 취소되어도 원본 인증 행은 삭제하지 않고 그대로 두고, 취소 행을 별도로 추가해 함께 노출(구분 태그 : 인증/취소, 처리일은 각 이력이 발생한 날짜)
  • 취소 행은 회색 처리·취소선으로 구분(다른 화면의 취소 상태 표시와 동일 컨벤션) — 정렬은 동일 학생·프로그램 기준으로 인증 행 바로 아래 취소 행이 오도록 처리일 오름차순
  • 학교(학교명)는 학교급과 별도 컬럼으로 노출 — B.1·B.6과 동일하게 학교급만으로는 특정할 수 없는 소속 학교를 함께 표시
  • 다면적 역량 컬럼은 B.6과 동일한 영역 dot(파랑=창의/초록=공감/보라=글로벌)으로 구분 표시
  • 점수는 해당 이수 건에서 취득한 개별 역량점수 — B.6의 학생별 총점수(3영역 합산)와는 다른 값이니 혼동 금지. 취소 행의 점수는 취소된 원 점수를 그대로 표기(음수 표기 아님)
  • 취소 처리 시 B.6 학생별 총점수·배지 등급 재계산에 반영 — 취소분 점수는 총점수 집계에서 제외

학생 목록이 있는 관리자 화면 표준 — 알림발송(이메일 채널)·그룹관리·그룹설정을 고정 노출한다. 중복 제거 키는 아이디(이메일). [새로고침]은 폼 reset이 아니라 검색조건 초기화(쿼리스트링 제거).
인증 이력은 취소되어도 삭제하지 않는다 — 원본 인증 행을 유지한 채 취소 행을 별도로 추가해 인증·취소 이력을 모두 남긴다(감사 추적 목적). 취소분 점수는 B.6 학생별 총점수·배지 등급 재계산 시 제외한다.
