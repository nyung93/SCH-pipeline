화면 정의
학생이 로그인 후 자신의 활동·역량점수·디지털 배지를 한눈에 확인하는 학생 전용 대시보드. 공통 학적필터·관리자용 그리드는 사용하지 않고 카드·요약 중심으로 구성.
1
최초 로그인 얼럿
  • A.4 통합 로그인에서 최초 로그인으로 접속한 계정이 마이페이지 진입 시 노출
  • 비밀번호 설정 전까지는 마이페이지 외 다른 기능 이용 제한
  • [비밀번호 설정하기] 클릭 시 PAGE 2 내정보 수정 화면으로 이동
2
학생 기본정보
  • 이름·학교·학년·반 표시, [정보 수정] 클릭 시 PAGE 2 내정보 수정 화면 이동
  • 신청 프로그램·수료 프로그램 건수, 총 역량점수 카드로 요약
3
역량점수 인증현황
  • 학생 기본정보와 2단 배치 · 현재 배지 등급(골드/실버/미획득) 및 창의·공감·글로벌 영역별 점수 요약
  • [배지·마일리지 상세] 클릭 시 C.4 디지털배지마일리지 화면으로 연계
4
배너 영역
  • AI 어드바이저 · 프로그램 신청 · 프로그램 신청내역 · 역량점수 현황 4종 바로가기
  • 클릭 시 각 해당 화면으로 이동
5
추천 프로그램 목록 (캘린더형)
  • 좌측 월간 미니캘린더 + 우측 일정 리스트 구성, 날짜별 등록 건수 표시
  • 날짜 클릭 시 해당일 일정으로 리스트 갱신, 리스트 클릭 시 프로그램 신청 화면 이동
  • [더보기] 클릭 시 전체 비교과 일정 화면으로 이동
