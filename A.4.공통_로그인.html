화면 정의
학생·관리자 통합 로그인 화면. 구분 탭으로 로그인 유형을 전환하며, 학생은 일반 로그인 외에 최초 로그인 방식을 별도 제공한다.
1
구분 탭
  • 학생 / 관리자 2종만 제공
2
학생 로그인 (일반)
  • 아이디(이메일 형식) · 비밀번호 입력 후 로그인
  • 하단 아이디 찾기 / 비밀번호 찾기 링크 제공 (5번 참조)
  • 상단 "최초 로그인이신가요?" 클릭 시 3번 폼으로 전환
3
학생 최초 로그인
  • 학교 · 학년 · 반 선택 + 학생이름 · 이메일 입력으로 본인확인
  • 로그인 성공 시 마이페이지로 이동, 비밀번호 설정 전까지 시스템 이용 제한
  • 비밀번호 설정 완료 후 이후부터는 일반 로그인 사용
4
관리자 로그인
  • 아이디 · 비밀번호 입력 후 로그인만 제공 (찾기 기능 없음)
5
아이디 · 비밀번호 찾기
  • 아이디 찾기 : 이름 · 학교 · 이메일 인증 → 마스킹된 아이디 표시
  • 비밀번호 찾기 : 아이디 · 이메일 인증 → 임시 비밀번호 발송
