비교과 프로그램 통계
연간 실시 현황 및 영역별(창의·공감·글로벌) 운영현황을 집계·조회하는 관리자 대시보드. (2026-08-27 개정) 운영완료 기준 실적(전체 프로그램수·참여 학생/학교수)·상태별 현황·부서별 운영현황·생성 프로그램 수(검색조건 무관) 신규 반영. (2026-08-28 개정) 검색조건 재구성 — 실시기간→조회기간(회계연도 기준)·연도/학기→연도·운영형태→프로그램 유형 명칭변경, 재원 추가, 다면적역량→역량 명칭변경, 프로그램명 삭제, 항목 순서 재배치. (2026-08-29 개정) 운영완료 기준 실적 요약을 대시보드 형태로 재구성 — 프로그램 실적/참여 현황/영역별 운영현황/배지 획득자 4개 섹션 + 섹션별 일러스트 아이콘, 배지 획득자(실버/골드) 참고 카드 추가. 주요 현황 요약(상태별)은 좌측 원형 그래프(도넛)·우측 상태 테이블 2단 구성으로 변경. (2026-08-30 개정) "프로그램별 실시 현황" 그룹을 화면에서 삭제 — 세부 데이터는 프로그램 통계·지원자 통계 Excel 2종 다운로드로만 제공. (2026-08-30 재변경) [양식보기] 버튼 삭제 — 다운로드 버튼 2개만 노출. (2026-08-31 개정) "프로그램 운영현황(전체)"(구 주요 현황 요약(상태별))과 "부서별 프로그램 운영 건수 및 참여 학생 수"를 주요현황 그룹 하나로 통합.

  • "실시기간"을 "조회기간(회계연도 기준)"으로 명칭변경(2026-08-28)
  • "연도/학기"에서 학기 select를 제거하고 "연도" 단일 항목으로 변경 — 학기 구분은 조회기간(날짜range)으로 대체
  • 연도 select 변경 시 조회기간이 해당 연도 03-01 ~ 오늘 날짜로 자동 설정된다(수동 재지정 가능) · 최초 접속 시 연도는 올해 연도가 기본값
  • "운영형태"를 "프로그램 유형"으로 명칭변경(옵션값 동일 : 일반참여형/심화 실습형)
  • "다면적역량"을 "역량"으로 명칭변경(옵션값 동일 : 창의/공감/글로벌)
  • 재원 검색조건 신규 추가 — 옵션 값은 B.3 비교과 프로그램 등록 화면에서 관리하는 재원 마스터 데이터를 그대로 가져온다(전체/글로컬대학사업/앵커사업/AI중심대학사업/교비). 본 화면에서 재원을 별도로 추가·삭제하지 않는다
  • 운영부서 옵션도 동일한 방식 — B.3 비교과 프로그램 등록 화면에서 관리하는 운영부서 마스터 데이터를 그대로 가져와 표시한다. 두 항목 모두 원천은 B.3이며, 총괄관리자가 B.2·B.3 화면의 [⚙ 관리] 팝업에서 추가·삭제하면 본 화면 select 옵션에도 즉시 반영된다
  • 프로그램명(텍스트 검색) 항목 삭제(2026-08-28)
  • 검색 액션 — 새로고침 · 조회
  • [새로고침] = 검색조건 초기화 — 폼 기본 경로로 이동해 쿼리스트링(hidden 페이지·정렬 포함)을 모두 털어낸 최초 진입 상태로 되돌린다
  • [새로고침]에 폼 reset 방식을 쓰지 않는다 — reset은 서버가 방금 렌더한 값(=직전 검색조건)으로만 되돌아가 조회 후에는 무동작으로 보이고, 페이지·정렬 값이 그대로 남는다
  • (2026-08-30 신규) "프로그램별 실시 현황"을 화면 목록에서 완전히 제거 — 위 검색조건을 반영한 세부 데이터는 Excel 다운로드로만 제공한다(그룹5 자체를 없애고 다운로드 버튼 2개를 본 그룹 하단으로 이동)
  • [프로그램 통계 다운로드] — 프로그램(차수) 단위 1행 : 운영일자·재원·운영부서·프로그램명·역량·프로그램 유형 + 신청/수료/취소 인원·수료율·만족도. 프로그램 1건에 참여 학교가 여러 곳일 수 있어 학교명은 포함하지 않는다
  • [지원자 통계 다운로드] — (2026-08-30 변경) 학교(참여교) 단위 1행 : 운영일자·재원·운영부서·학교명·프로그램명·역량·프로그램 유형 + 신청/수료/취소 인원·수료율·만족도(해당 학교 소속 학생만 집계). 한 프로그램에 참여 학교가 여럿이면 학교 수만큼 행 생성
  • (2026-08-30 삭제) [양식보기] 버튼 제거 — 다운로드 버튼 2개만 노출

동작 규칙

  • [프로그램 실적] 전체 프로그램 수 — 운영완료 상태 프로그램만 집계(신규 정의, 2026-08-27) / 총 신청 인원(연인원, 프로그램별 신청 건수 합산)·수료 인원·취소 인원 집계
  • [참여 현황] 전체 참여 학생수(신규) — 학생 기준 중복 제거 순인원 / 전체 참여 학교수(신규) — 참여 학생이 1명 이상인 초·중·고 학교 수 / 학교급별 참여 현황 — 초·중·고 각각 참여 학생수 + 참여 학교수 병기
  • [영역별 운영현황] 창의·공감·글로벌 운영현황 조회, 대시보드 차트(bar)로 표현
  • [배지 획득자](2026-08-29 신규) — 실버·골드 배지 획득자 수를 참고 카드로 표시. B.6 역량인증제관리의 실시간 값을 그대로 가져오며 본 섹션에서 직접 집계하지 않는다 — 집계 대상(엔티티)이 달라 그룹1의 운영부서·재원·프로그램 유형은 반영되지 않고 학교급·역량만 반영된다
  • 위 3개 섹션(프로그램 실적·참여 현황·영역별 운영현황) 지표는 그룹1 검색조건(연도·조회기간·재원·운영부서·학교급·역량·프로그램 유형)을 그대로 반영 — 배지 획득자 섹션은 예외(위 참고)

"전체 프로그램 수"는 운영완료 상태만 집계한다(2026-08-27 정의). "생성 프로그램 수"(금일/주간/월간)는 상태와 무관하게 등록된 건수이며 검색조건의 기간(연도·조회기간)과는 별개로 상시 집계된다 — 기간 축이 이미 지표 자체에 내포되어 있어 중복 적용하지 않는다.
검색조건 "조회기간"은 회계연도 기준이다 — 연도 select 변경 시 해당 연도 03-01 ~ 오늘 날짜로 자동 설정되며(최초 접속 시 연도는 올해가 기본값), 사용자가 조회기간을 직접 재지정할 수도 있다. "재원"·"운영부서"는 본 화면이 직접 관리하는 값이 아니라 B.3 비교과 프로그램 등록 화면의 마스터 데이터를 그대로 가져온 것이다 — 총괄관리자가 B.2·B.3의 [⚙ 관리] 팝업에서 추가·삭제하면 본 화면 검색조건에도 동일하게 반영된다(2026-08-28).
배지 획득자 수(실버/골드)는 학생의 누적 총점 기준 상태값으로 본 화면과 집계 대상(엔티티)이 다르다 — 원천·상세 관리는 B.6 역량인증제관리이며, 본 화면 그룹2에는 참고용 카드로만 표시한다(2026-08-29 추가, 직접 집계 아님). 시스템 접속 통계(방문자 수 등)는 본 화면과 무관한 도메인으로 별도 화면(B.10)에서 제공한다.
