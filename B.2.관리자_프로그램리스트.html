2 검색액션
동작 규칙
  • 새로고침 · 조회
  • [새로고침] = 검색조건 초기화 — 폼 기본 경로로 이동해 쿼리스트링(hidden 페이지·정렬 포함)을 모두 털어낸 최초 진입 상태로 되돌린다
  • [새로고침]에 폼 reset 방식을 쓰지 않는다 — reset은 서버가 방금 렌더한 값(=직전 검색조건)으로만 되돌아가 조회 후에는 무동작으로 보이고, 페이지·정렬 값이 그대로 남는다
3 선택 프로그램 액션
동작 규칙
  • 목록 체크박스로 다중 선택 후 운영상태 드롭다운에서 값을 고르고 [적용] 클릭 시 선택된 프로그램 전원에게 일괄 반영
  • 드롭다운에는 5개 상태(작성중/모집중/모집마감/운영완료/취소)를 모두 노출 — 자동 계산 상태(모집중·모집마감)도 관리자가 필요 시 수동으로 덮어쓸 수 있다
  • 취소 대상 중 지원자가 1인 이상인 프로그램이 포함된 경우 [적용] 클릭 시 취소 불가 얼럿을 표시하고 해당 건은 일괄 처리에서 제외한다
4 프로그램 목록
동작 규칙
  • 프로그램명 · 상태 · 운영부서 · 담당자 · 모집·교육기간 · 재원 · 운영형태 · 다면적역량 표시 / 구분 컬럼 삭제
  • 지원 현황 : 전체 · 신청 · 승인 · 수료 · 취소 · 불가 인원수를 프로그램별로 표시(2026-09-02 변경 — 기존 7항목에서 대기 삭제, 참여→승인·불참→불가로 명칭 변경)
  • B.4 지원자 관리의 상태 집계 카드와 동일한 6개 항목으로 반영
  • 다면적역량 컬럼은 B.6·B.9와 동일한 영역 dot(파랑=창의/초록=공감/보라=글로벌)으로 구분 표시
  • 운영상태 5단계 : 작성중(최초 저장, 모집중 이전 상태) → 모집중(조회일자가 신청기간 시작일~종료일 사이면 자동 지정) → 모집마감(신청기간 종료일 경과 시 자동 처리) → 운영완료/취소(학교가 직접 변경)
  • 취소 상태 프로그램은 학생·교사 화면(A.3·A.5·E.1 등)에 노출되지 않으며 통계(B.5)에도 영향을 주지 않는다
5 행 관리
동작 규칙
  • [지원자 관리] 클릭 시 해당 프로그램의 B.4 지원자 관리 화면으로 이동
  • 이동 후 화면 타이틀은 선택한 프로그램명으로 표시
  • [복사] 클릭 시 해당 프로그램을 동일 내용으로 신규 생성 — 프로그램 key는 새로 채번, 프로그램명 뒤에 [복사] 표시를 붙여 원본과 구분, 생성 직후 상태는 작성중
  • [수정] 클릭 시 B.3 비교과 프로그램 등록 화면을 값이 채워진 수정 모드로 재사용(등록 폼 재구현 금지)
  • [취소](행 관리 드롭다운/일괄변경 공통) 대상 프로그램에 지원자가 1인 이상 있으면 취소 불가 얼럿을 표시하고 처리하지 않는다
  • [복사]·[수정]·[삭제] 권한 : 총괄관리자는 전체 프로그램에 권한 발생 / 부서운영자는 본인 소속 운영부서 및 본인이 등록한 프로그램에 한해서만 권한 발생 — 그 외 프로그램은 버튼 비활성화(회색 처리), 화면 입력이 아닌 로그인 계정 기준으로 서버단에서 강제(스타일규칙 5-1항과 동일 원칙)

! 표준 규칙 · 예외
지원 현황 6개 항목(전체·신청·승인·수료·취소·불가)은 B.4 지원자 관리의 상태 집계 카드와 동일 기준(2026-09-02 변경 — 기존 신청/대기/참여/수료/취소/불참 7단계에서 대기 삭제, 참여→승인·불참→불가로 명칭 변경). Excel 좌측 · 페이징 중앙.
부서운영자로 로그인한 경우 복사·수정·삭제 권한 범위는 본인 소속 운영부서 및 본인이 등록한 프로그램으로 제한된다 — 화면 입력이 아닌 로그인 계정 기준 서버단 강제(스타일규칙 5-1항과 동일 원칙). 총괄관리자는 제한 없이 전체 프로그램에 권한 발생. 등급권한은 B.8 사용자 관리에서 부여(2026-08-27 변경 — 기존 총괄관리자 전용에서 부서운영자 스코프 접근으로 예외 허용).
취소 제한 — 지원자가 1인 이상인 프로그램은 취소 처리 불가(얼럿 표시). 취소된 프로그램은 학생·교사 화면 비노출, 통계 미반영.
