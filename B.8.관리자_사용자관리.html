화면 B.8
사용자 관리
관리자 계정을 총괄관리자 / 부서운영자 2단계 등급권한으로 관리하는 화면(서비스관리 > 사용자 관리). 총괄관리자는 전체 메뉴에 접근하며, 부서운영자는 본인 소속 운영부서가 등록·운영하는 프로그램 관리 기능(B.3·B.4·B.5)만 이용할 수 있다. 대학 원본 화면의 교수·조교·겸임소속·상담사소속 등 고등교육 특유 항목은 제외하고, 본 프로젝트(초·중·고 대상)에 맞게 등급권한·부서권한 중심으로 재구성했다(2026-08-27 신설).

동작 규칙
  • 대학 원본 화면의 소속(대학/학과), 겸임소속, 상담사소속, 교직원등록 체크박스는 본 프로젝트에 미반영 — 초·중·고 대상이라 교수·조교 등 고등교육 소속체계가 없음
  • [새로고침] = 검색조건 초기화(쿼리스트링 제거) — 폼 reset 방식 금지, 공통 규칙과 동일
  • 조회 화면은 총괄관리자 전용 — 부서운영자는 본 화면 접근 권한 자체가 없다(로그인 권한으로 서버단 차단)
2 선택 사용자 액션
동작 규칙
  • 목록 체크박스로 다중 선택 후 등급권한 드롭다운 또는 부서권한 드롭다운에서 값을 고르고 [적용] 클릭 시 선택된 사용자 전원에게 일괄 반영
  • 등급권한을 총괄관리자로 일괄 변경하면 해당 대상들의 부서권한 값은 자동 해제된다(4번 팝업의 규칙과 동일)
  • 본인 계정을 선택해 등급권한을 낮추거나 로그인 불가로 변경하는 것은 차단 — 최소 1명의 총괄관리자는 항상 유지되어야 한다

4 교직원등록 / 수정
동작 규칙
  • 이름·아이디·비밀번호는 관리자가 직접 입력해 즉시 계정 생성 — B.7 교사 임시계정과 달리 유효기간 없이 계속 사용
  • 아이디 중복확인 필수, 비밀번호는 2종 이상 조합 10자 이상(공통 규칙과 동일)
  • 등급권한 = 부서운영자 선택 시에만 소속 운영부서 select 활성화 및 필수 입력으로 전환
  • 목록 [보기] 클릭 시 동일 팝업을 값이 채워진 수정 모드로 재사용(등록 폼 재구현 금지)
  • 비밀번호는 등록 시 1회만 관리자가 지정 — 이후 본인이 로그인 후 변경(비밀번호 변경 기능은 본 화면 범위 밖, 확인 필요)

S1

S4

S5
고등교육 항목 제외대학 원본 화면의 교수·조교·겸임소속·상담사소속 항목은 미반영(초·중·고 대상)
! 표준 규칙 · 예외
부서운영자의 프로그램 관리 조회범위는 화면 입력이 아닌 로그인 계정의 소속 운영부서로 서버단에서 강제한다(스타일규칙 5-1항과 동일 원칙) — B.3 프로그램 등록·B.4 지원자 관리·B.5 통계에 적용되며, B.1 학생조회·B.2 프로그램리스트·B.6 역량인증제관리·B.7 교사 임시계정 관리는 총괄관리자 전용이다.
등급권한이 총괄관리자인 계정은 소속 운영부서를 지정하지 않는다 — 부서권한 선택은 부서운영자에게만 필수이며, 총괄관리자로 전환 시 기존 부서권한 값은 자동 해제된다.
[늘리기]·[일괄삭제] 생성 금지 — 팀 표준 제외.
교수·조교 등 고등교육 특유 소속등급 미반영 — 본 프로젝트는 초·중·고 대상이므로 대학 원본 화면의 소속(대학/학과)·겸임소속·상담사소속 개념을 가져오지 않는다.
