5 안내 사항
이메일이 이미 등록된 학생은 기존 계정에 신청 이력이 반영됩니다. 이메일이 시스템에 없는 학생은 임의생성 학생으로 신규 등록됩니다(B.1 임의생성 학생과 동일 개념).
임의생성된 학생은 최초 로그인 시 개인정보 동의 및 비밀번호 설정이 필요합니다(C.1 학생 최초 로그인과 동일 절차). 설정 완료 전까지 마이페이지 외 기능 이용이 제한됩니다.
오류 행(이메일 누락·학년 형식 오류 등)은 등록 대상에서 자동 제외됩니다. 수정 후 재업로드하거나, 오류 행을 제외하고 나머지만 등록할 수 있습니다.

3 학생 명단 업로드
입력 항목
  • 학교(필수, 검색 선택) — 엑셀 파일에는 학교명 컬럼 불필요, 선택한 학교값 일괄 적용
  • 엑셀 컬럼(순서 고정) : 이메일 · 학생명 · 학년 · 반 · 번호
동작 규칙
  • 학교를 먼저 선택해야 업로드 영역 활성화 — 미선택 시 드롭존 비활성
  • 엑셀 양식 다운로드 제공(고정 컬럼 순서로 제공)
  • 이메일은 필수값, 기존 회원 매칭 기준 — B.4 엑셀 일괄등록 규칙과 동일 컬럼/검증 로직 공유
4 업로드 결과 검증
동작 규칙
  • 이메일이 기존 회원과 일치하면 해당 계정에 신청 반영, 불일치 시 이메일·학생명·학교·학년만 필수로 임의생성 학생 계정 생성(B.1 임의생성 개념 재사용)
  • 행 단위로 처리 결과(기존회원 매칭/신규 생성/오류) 표시, 오류 행은 케이스별 사유를 비고 컬럼에 구분 표시
  • 오류 케이스 : 이메일 누락, 학년 형식 오류, 반 형식 오류(숫자 외 입력), 이메일 중복(행 간 동일 이메일) 등
  • 오류 행은 등록 대상에서 자동 제외 — 수정 후 재업로드 또는 정상 행만 선택 등록 가능
